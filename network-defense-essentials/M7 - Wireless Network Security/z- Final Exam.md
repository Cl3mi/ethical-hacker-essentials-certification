Here are the answers to the questions:

1. **Question 1**

   **Which of the following technologies belongs to the IEEE 802.16 family of wireless networking standards whose signals can function over several miles with data rates reaching up to 75 Mbps?**
   
   - **WiMAX**

   **Explanation:** WiMAX (Worldwide Interoperability for Microwave Access) is part of the IEEE 802.16 family and is designed to provide wireless data over long distances, with data rates up to 75 Mbps.

2. **Question 2**

   **Which of the following types of antenna is a straight electrical conductor measuring half a wavelength from end to end, and it is connected at the center of the RF feed line and is used for supporting client connections rather than site-to-site applications?**
   
   - **Dipole antenna**

   **Explanation:** A dipole antenna is a basic type of antenna consisting of a straight conductor that is half a wavelength long. It is commonly used for point-to-point or client connections rather than long-range, site-to-site applications.

3. **Question 3**

   **Norman, a security professional, was instructed to enhance the security of wireless network in the organization. Norman thus implemented a wireless encryption technology that uses RADIUS for centralized client authentication using multiple authentication methods, such as token cards, Kerberos, and certificates. Identify the technology implemented by Norman in the above scenario.**
   
   - **WPA2 Enterprise**

   **Explanation:** WPA2 Enterprise uses RADIUS servers for centralized authentication and supports various authentication methods, including token cards, Kerberos, and certificates. It provides stronger security than WPA2 Personal.

4. **Question 4**

   **Annie, a security professional, has been tasked to implement Wi-Fi authentication in her organization to secure the wireless communication. For this purpose, she implemented an authentication process in which the station and AP use the same WEP key to provide authentication, and Annie enabled and configured the key manually on both the AP and client. Identify the Wi-Fi authentication method employed by Annie in the above scenario.**
   
   - **Shared key authentication process**

   **Explanation:** The shared key authentication process involves using a pre-shared WEP key for authentication between the wireless station and the access point. This method requires manually configuring the key on both ends.

5. **Question 5**

   **Which of the following countermeasures can help a user defeat WPA cracking attempts?**
   
   - **Implement a NAC or NAP solution for additional control**

   **Explanation:** Implementing a Network Access Control (NAC) or Network Access Protection (NAP) solution adds an extra layer of security by controlling and monitoring access to the network, which helps to defend against WPA cracking attempts. A strong passphrase is also important, but the options provided focus on additional control measures.
