# Network Security Controls

## Administrative Security Controls
- **Objective**: Manage and ensure the security of administrative access and organizational safety.

### 1. Regulatory Framework Compliance
- **Example**: HIPAA for medical data protection.
- **Goal**: Ensure compliance with industry-specific regulations through appropriate security controls.

### 2. Security Policy
- **Importance**: Defines and enforces security measures across the organization.
- **Impact**: Policies like password length (e.g., 20 characters) affect all systems, from user accounts to IoT devices.
- **Role**: Vital for establishing and maintaining network protection.

### 3. Employee Monitoring and Supervision
- **Purpose**: Track and monitor employee activities to detect unusual behavior.
- **Example**: Identifying irregular login times (e.g., 3:00 AM logins) to detect potential issues.

### 4. Information Classification
- **Purpose**: Categorize information based on its sensitivity (e.g., secret, top secret).
- **Application**: Used in both government and private sectors to manage and protect different levels of information.

### 5. Security Awareness and Training
- **Objective**: Educate employees about security threats and proper responses.
- **Activities**: Includes training sessions, briefings on recent threats, and encouraging knowledge dissemination throughout the organization.

## Physical Security Controls
- **Purpose**: Prevent unauthorized physical access to devices and facilities.

### Examples
- **Locks and Fences**: Basic physical barriers to access.
- **Badging Systems**: Identity verification for entry.
- **Security Guards**: Personnel to monitor and control access.
- **Mantrap Doors**: Security entry systems with two doors and an intermediate checkpoint.
- **Biometric Systems**: Fingerprints, retina scans, etc., for identity verification.
- **Lighting**: Illuminates areas to deter unauthorized persons.
- **Motion Detectors**: Detects movement within secured areas.
- **Closed Circuit TV (CCTV)**: Surveillance and recording of activities.
- **Alarms**: Alerts for unauthorized access attempts.

## Technical Security Controls
- **Definition**: Measures taken to protect systems from unauthorized access and attacks.
- **Components**:
  - **Access Control**: Authentication and authorization of users.
  - **Auditing**: Tracking and recording user activities (logins, application usage).
  - **Security Protocols**: Protocols used to secure communications and data.
  - **Network Security Devices**:
    - **Firewalls**: Control incoming and outgoing network traffic.
    - **Intrusion Detection Systems (IDS)**: Detects and alerts on potential threats.
    - **Intrusion Prevention Systems (IPS)**: Prevents and blocks identified threats.

- **Focus**: A comprehensive set of measures designed to safeguard resources from unauthorized personnel.
