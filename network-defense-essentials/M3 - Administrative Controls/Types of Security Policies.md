## Summary: Types of Information Security Policies and Internet Access Policies

### Types of Information Security Policies

1. **Enterprise Security Policy (EISP)**
   - **Scope**: Applies to the entire organization.
   - **Purpose**: Provides overall direction for security policies.
   - **Examples**:
     - Application policy for software.
     - Network device security.
     - Backup and restore policies.
     - System security.

2. **Issue-Specific Security Policy (ISSP)**
   - **Scope**: Focuses on specific issues or technology-based systems.
   - **Purpose**: Directs usage of particular technology systems.
   - **Examples**:
     - Wireless security policies.
     - Incident Response Plan (IRP).
     - Password policies for personal devices.

3. **System-Specific Security Policy (SSSP)**
   - **Scope**: Applies to specific systems.
   - **Purpose**: Provides detailed policies for particular systems.
   - **Examples**:
     - Security measures for the Demilitarized Zone (DMZ).
     - Encryption protocols for specific systems.
     - Intrusion detection and prevention systems.
     - Access control policies.

### Internet Access Policies

1. **Promiscuous Policy**
   - **Description**: No restrictions on internet access.
   - **Examples of Access**: 
     - Visiting any website or downloading any content.
     - No controls over sites like Pirate Bay or gambling sites.
   - **Typical Organizations**: Small Office/Home Office (SOHO), personal use.

2. **Permissive Policy**
   - **Description**: Allows broad access but blocks known dangerous services.
   - **Examples of Access**:
     - General unrestricted access, with exceptions for dangerous or compromised sites.
   - **Typical Organizations**: Small to medium-sized businesses with some security measures.

3. **Prudent Policy**
   - **Description**: High security with selective allowance for necessary and safe services.
   - **Examples of Access**:
     - Limited access to safe, necessary services only.
     - Blocks everything else.
   - **Typical Organizations**: Corporate offices, businesses with moderate to high security needs.

4. **Paranoid Policy**
   - **Description**: Complete block on all internet access.
   - **Examples of Access**:
     - No access to any websites, including common sites like Google.
   - **Typical Organizations**: Highly secure government installations, top-tier secure projects.

### Password Policy Considerations

- **Password Length and Complexity**
  - **Length**: Define minimum and maximum password lengths.
  - **Complexity**: Require combinations of uppercase, lowercase, numbers, and special characters.

- **Blacklist Management**
  - **Purpose**: Prevent the use of commonly breached passwords.
  - **Method**: Create and maintain a blacklist of frequently used and compromised passwords.

- **Password Duration**
  - **Definition**: Set guidelines for how often passwords should be changed (e.g., every few weeks or months).

- **Common Password Practices**
  - **Recommendations**: Implement best practices for creating and managing passwords to enhance security.

### Summary

- **EISP, ISSP, and SSSP**: Different types of policies that address organizational-wide security, specific issues, and particular systems respectively.
- **Internet Access Policies**: Range from no restrictions (promiscuous) to complete block (paranoid), with varying levels of access control.
- **Password Policies**: Focus on length, complexity, blacklisting, duration, and best practices to ensure strong and secure passwords.
