### Introduction
- **Identity Access Management (IAM)**: A critical concept for managing access to resources, ensuring entities have appropriate access at the right time.

### Key Concepts of IAM
- **Authentication**: Answers the question, "Who are you?"
  - Process of verifying the identity of a user or entity.

- **Authorization**: Answers the question, "What can you do?"
  - Determines the permissions and actions a user or entity is allowed to perform.

- **Identity Management**: Involves creating and managing user identities.
  - Provides interfaces and tools for administrators.
  - Includes a repository of all entities and their access rights.

### Identity Management Systems
- **Examples**: Microsoft's Active Directory (both on-premise and Azure).
  - **Active Directory**: Allows extensive management of user identities and access controls.
  - **Azure Active Directory**: Cloud-based version with additional features for cloud services.

### Identity Management Process
1. **Human Resources and CRM Integration**
   - HR systems collaborate with IAM systems to manage employee identities.
   - Example: When a new employee, such as Kevin King, joins XYZ Corp, HR and IAM systems work together to create and manage his identity.

2. **Identity Creation and Access**
   - New employees are assigned identities that grant access to relevant resources.
   - Example: An employee in the engineering department will receive access to engineering applications and resources.

3. **Role of Approvers and Administrators**
   - Approvers (e.g., managers) and system administrators manage and control access to the identity repository.

### User Identity Management (IDM)
- **Subset of IAM**: Focuses specifically on user identification.
  - Ensures users always have a valid identity to access resources.

- **User Identity Attributes**
  - **Examples**: Username, account number, job role, office address, picture, password, etc.
  - All attributes are stored in identity repositories (databases).

### Practical Implementation
- **Active Directory**: Allows modification and addition of user attributes within the identity repository.
  - Provides comprehensive tools for managing user identities and access permissions.
 
### Summary
- **IAM**: Manages the right entities with the right access at the right time.
- **Authentication and Authorization**: Core components of IAM.
- **Identity Management Systems**: Examples include Active Directory (on-premise and Azure).
- **IDM**: Ensures valid user identities and stores user attributes.
