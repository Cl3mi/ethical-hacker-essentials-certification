## Overview
Data encryption ensures that data is only accessible to authorized individuals and is protected from unauthorized access. The script details three major types of encryption: **disk encryption, file-level encryption, and removable media encryption.**

## Key Encryption Types

### 1. Disk Encryption
- **Purpose**: Encrypts the entire hard drive of a device.
- **Scenario**:
  - **Example**: If a laptop is stolen, the hard drive is encrypted.
  - **Protection**: Even if the thief removes the hard drive and connects it to another device, the data remains inaccessible without proper decryption.
  - **Components**:
    - **Encrypted Data**: All data on the disk is encrypted except for potentially the Master Boot Record (MBR) or GUID Partition Table (GPT).
    - **Impact**: Ensures that sensitive data, such as personal or business information, remains secure despite physical theft of the device.

### 2. File-Level Encryption
- **Purpose**: Encrypts individual files or folders.
- **Method**:
  - **Example**: Right-click on a file or folder and apply encryption according to a chosen algorithm.
  - **Scope**: Only the specified files or folders are encrypted, not the entire disk.

### 3. Removable Media Encryption
- **Purpose**: Encrypts data on removable storage devices.
- **Devices Covered**:
  - **Examples**: Flash drives, smartphones, tablets, portable hard drives, digital cameras.
- **Scenario**:
  - **Example**: When a removable device is connected to a computer, it requires encryption to be accessible.
  - **Protection**: Ensures that data on these devices is secure from unauthorized access.

## Summary
The three types of encryption—**disk encryption, file-level encryption, and removable media encryption**—provide comprehensive security for data. Disk encryption protects all data on a hard drive, file-level encryption secures specific files or folders, and removable media encryption safeguards data on portable storage devices. Each method ensures that data remains protected and inaccessible to unauthorized individuals, enhancing overall data security.
