
- **hping3**:
  - Command-line tool for packet crafting and network testing.
  - Can manipulate TCP flags and send customized ICMP, TCP, or UDP packets.
  - Used for flooding attacks (--flood option).

- **High Orbit Ion Cannon (HOIC)** and **Low Orbit Ion Cannon (LOIC)**:
  - **HOIC**: Allows DDoS attacks against any IP address or user.
  - Notable for its humorous interface with buttons like "FIRE TEH LAZER" and "IMMA CHARGIN MAHLAZER."
  
  - **LOIC**: Floods target sites with TCP, UDP, or HTTP packets to disrupt services.
  - Available for Android platforms, enabling attacks from mobile devices.
  
- **Caution and Legality**:
  - These tools are powerful and freely available for download.
  - Users are cautioned against using them without proper authorization.
  - Only ethical and legal use, with explicit permission from targets, is advised.

- **Other DDoS Tools**:
  - **XOIC**, **HULK**, **Slowloris**, **Pyloris**, and others are also used for DDoS attacks.
  - Each tool has specific capabilities for overwhelming target systems with traffic.
