1. **EC-Council LPT (Licensed Penetration Tester):**
   - A well-known methodology for pen testing.

2. **IBM ISS:**
   - Provided by IBM, focused on information security and vulnerability assessments.

3. **McAfee Foundstone:**
   - Developed by McAfee for security testing and vulnerability management.

4. **Open-Source Methodologies:**
   - **OSSTMM (Open Source Security Testing Methodology Manual):** A comprehensive guide for security testing and metrics.
   - **ISSAF (Information Systems Security Assessment Framework):** Provides guidelines for assessing the security of information systems.
   - **NIST (National Institute of Standards and Technology):** Offers various standards and guidelines for cybersecurity.
   - **OWASP (Open Web Application Security Project):** Focuses on securing web applications and their vulnerabilities.
   - **CREST (Council of Registered Ethical Security Testers):** A framework for providing accredited security testing services.

### Key Points
- **Commonalities:** Most methodologies follow similar paths in terms of approach and processes, with variations tailored to specific environments or requirements.
- **Flexibility:** As a professional pen tester, you may need to adapt to different methodologies based on client requests. For example, if a client prefers CREST over EC-Council LPT, you should be prepared to study and apply the preferred methodology.
- **Adaptation:** It is essential to be familiar with multiple methodologies and adapt to the one required by the client for effective and compliant penetration testing.
