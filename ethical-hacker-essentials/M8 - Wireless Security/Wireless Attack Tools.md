**Pre-Sharing Key Cracking:**
- After capturing pre-shared keys, they must be run through cracking programs to determine the actual passwords.
- Simple, short passwords (up to 8-10 characters) are easier to crack compared to complex ones.
- Strong passphrases are more secure and challenging to crack, even with powerful machines or cloud services like AWS.

**Aircrack-ng Suite:**
- **Aircrack-ng**: Main tool for cracking WPA/WPA2 PSK, WPA3, and WEP keys.
- **Airbase-ng**: Captures handshakes and can act as an ad-hoc network.
- **Aircrack**: For PSK cracking.
- **Airdecap**: Decrypts wireless headers and packets.
- **Airgraph**: Visualizes client-to-AP relationships.
- **Airmon-ng**: Puts Wi-Fi into monitor mode.
- **Airtun-ng**: Monitors encrypted traffic and injects arbitrary traffic.
- **Easside-ng**: Communicates with WEP-encrypted APs without the key.
- **Packetforge-ng**: Creates encrypted packets for injection.
- **Airdecloak-ng**: Removes WEP cloaking from pcap files.
- **Airdrop**: Rules-based deauthentication.
- **Airplay-ng**: Generates fake traffic.
- **Wesside-ng**: Quickly cracks WEP keys.
- **Airodump-ng**: Captures packets, including WEP initialization vectors.
- **Airolib-ng**: Manages ESSID password lists.
- **Airserv-ng**: Allows multiple programs to use a Wi-Fi card via TCP connection.
- **Tkiptun-ng**: Injects frames for WPA TKIP networks.
- **Wzook**: Recovers WEP keys from Windows XP's Wireless Zero Configuration Utility.

**Other Tools:**
- **AirMagnet Wi-Fi Analyzer PRO**: Provides visual analysis of Wi-Fi networks.
- **Ettercap and Bettercap**: Mainly used for man-in-the-middle attacks.
- **Wifiphisher, Reaver, Fern, and Elcomsoft**: Additional tools for Wi-Fi analysis, cracking, and security.
